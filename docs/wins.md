# Wins

Real cases where someone got a big company to fix a problem, with the step that worked. Each one links to the playbook it used.

Share yours with the [Share a win](https://github.com/alexgaoth/escalate-anything/issues/new?template=share-your-case.yml) form. If your agent kept a case log, this prints a write-up without reference numbers, names or account details:

```bash
uvx escalate-anything cases <id> --story
```

Only cases whose authors ticked "You may quote this case" are listed here. Amounts are what the person reported.
